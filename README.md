## Дүгнэлт (Хэсэг E)

Хамгийн үр дүнтэй нь Supermodel (GUI) аялал байсан: үүгээр «Нийт ном» тоолуурын зөрүү (BUG-01), оны таслалтай харагдалт (BUG-06), хайлтын том/жижиг үсгийн согог (BUG-07) олдсон. Saboteur (API) аялалаар буруу JSON-той POST хүсэлтэд 400 биш 200 OK буцаадаг согог (BUG-10) олдсон бөгөөд нотолгоо нь evidence/bug-10-curl.txt-д бий. API-ийн хариунаас UI-аар нэмсэн номын он тэмдэгт мөр болж хадгалагдаж байгааг (BUG-09) мөн харсан. Charter-аас гадуур санамсаргүй олдсон нь тоолуурын зөрүү ба оны таслал. Мессежүүд, урт гарчигны харагдац, «Устгах» товчийн өнгийг бүрэн шалгаагүй тул тэдгээр нь дараагийн session-ий charter болно. Эхний session-д charter бөглөгдөөгүй загвараараа commit хийгдсэн тул charter-ийг дараа нь бөглөж, 2 дахь session-ийг charter-ийн commit-оос хойш шинээр хийсэн. Эхний session-ий зарим согогийг (хоосон талбар, давхардал) 2 дахь session-д дахин гаргаагүй тул bug report-д оруулаагүй. Автомат Playwright тест нь «Нийт ном»-ын тоо (BUG-01), хайлтын үр дүн (BUG-07), API-ийн статус код (BUG-10)-ыг assert-ээр шалгаж барих боломжтой байсан. Оны таслал зэрэг харагдацын зөрүүг тусгайлан assert бичиж өгөөгүй бол автомат тест алгасах тул зөвхөн хүний нүдээр олдох байсан.
