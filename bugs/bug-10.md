# BUG-10: POST /api/books буруу JSON биетэй хүсэлтэд 400 биш 200 OK буцаана

Орчин:  Уншлагын жагсаалт v2.0, Google Chrome 154.0.8037.97, Ubuntu Linux, 2026-10-20

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Терминалд `node app.js` ажиллуул.
2. Өөр терминалд ажиллуул:
   `curl -si -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{буруу json'`
3. Хариуны эхний мөрийг хар.

Хүлээгдэж байсан: Буруу JSON биетэй POST хүсэлтэд 400 алдаа (спецификаци).
Бодит үр дүн:     `HTTP/1.1 200 OK` буцна.
Ноцтой байдал: Major — сервер буруу хүсэлтийг амжилттай гэж хариулж, клиент алдааг мэдэхгүй.
